          Verify

          Verify your download.

          Verify the signed checksum file, then check the release file you downloaded against it.

          Signed checksum file
          minisign -Vm Ratspeak.sha256 -P RAT…
          Downloaded release file
          shasum -a 256 -c Ratspeak.sha256

          Stable releases publish release-file hashes, a signed checksum file, and a pinned public key in the Ratspeak README and docs.
