rsNode is LoRa firmware for Heltec V3 and V4 boards, in private beta.

How rsNode works

It runs in one of two modes, chosen on the device. As an RNode, it is the radio for one app, over USB, Bluetooth or Wi-Fi. As a Repeater, it forwards traffic on its own. Bluetooth is off while Wi-Fi is on. Managers are optional and only manage a Repeater.

For a beta password, email mail@ratspeak.org.

Accept the beta terms to see the boards.

rsNode private beta

Check the chip marking or your order details: ESP32-S3R2 has 2 MB PSRAM; ESP32-S3R8 has 8 MB. Both V4s have 16 MB flash and need different firmware.

Install erases the node: identity, managers, Wi-Fi, Bluetooth pairings and Repeater settings. Update requires a compatible package and firmware that supports USB updates.

                        rsNode device management
                    
                    Optional · Owner and Admins of a Repeater, over USB
                    
                
                
    
                    
    Next: press RESET on the board. Optional: add managers if this node will run as a Repeater you manage remotely.
    
                    
    Managers are optional. They manage this node over the mesh while it runs as a Repeater; an RNode ignores them.
    
                    
    
                        
    
                            
    
                                
    
                                    Managers
                                    
      
                                    
      Add yourself as the Owner with your Ratspeak LXMF address, or read the node to see its managers.
      
                                    
      
                                        
                                        
                                        
                                        
      The Owner changes settings and managers. Admins read status and settings and install updates. Settings access requires firmware that supports it.
      
                                        
      
                                            
                                            
                                        
      
                                        
      
                                    
      
                                    
      A node holds up to 4 managers.
      
                                
      
                            
      
                            
      
                                
       Before you save
      
                                
        
                                    
      • Plug the node in over USB. Close other apps that use its port, such as Ratspeak or a serial monitor.
        • 
                                    
      • If you just installed, press RESET on the board first.
        • 
                                    
      • Some betas require RNode mode for manager changes: stop and exit the Repeater first if a change is refused. In RNode, hold USB on the home menu to take over from another app.
        • 
                                    
      • Adding the first manager creates the node's identity, so its Bluetooth or Wi-Fi radio must be running (a normal RNode boot has one).
        • 
                                
      
                            
      
                            
      
                                
                                
                                
      Nothing to save yet. Add a manager.
